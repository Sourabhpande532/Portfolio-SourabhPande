
> # Portfolio Website 🌐

Welcome to my portfolio website repository! This repository contains the source code for my personal portfolio website, where I showcase my work and skills in the field of web development and design.

## Features ✨

- **About Section**: Introduces visitors to my portfolio, providing a concise overview of my engineering background and core areas of expertise.
- **Projects Section**: Showcases a curated selection of full-stack and AI-powered projects, complete with descriptions, screenshots, tech stacks, live demos, and GitHub repositories.
- **Skills Section**: Categorized overview of my frontend, backend, database, and AI/developer tooling proficiencies.
- **Blogs Section**: Features technical articles on web development, CI/CD automation, and core JavaScript concepts published on Hashnode to share knowledge with the developer community.
- **Connect Section**: Offers a direct way for recruiters and collaborators to get in touch through email and professional profiles.

## Technologies Used 💻

- Semantic HTML5
- Modern Vanilla CSS3
- Vanilla JavaScript
- Git
- Netlify
